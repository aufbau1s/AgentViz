# Code of Conduct

AgentViz should be a practical, welcoming project for people building tools around agentic workflows.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent while still being precise.
- Critique ideas, designs, and code without attacking people.
- Make room for contributors with different experience levels.
- Keep discussions focused on improving the project.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Discriminatory language or conduct.
- Doxxing or sharing private information without consent.
- Repeatedly derailing project discussions.
- Spam or bad-faith participation.

## Reporting

If you see behavior that makes the project unsafe or unwelcoming, open a private communication channel with the maintainer. If GitHub security advisories or private contact details are added later, this file should be updated with the preferred reporting path.

Maintainers may remove comments, close issues, block users, or take other action needed to keep the project healthy.
